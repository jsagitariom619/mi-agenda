# Mi Agenda — Deployment

El proyecto está conectado a Vercel mediante el repositorio `jsagitariom619/mi-agenda`.

Incluye el módulo de **Préstamos** con:
- prestatario y teléfono opcional
- monto y fecha del préstamo
- interés mensual opcional
- fecha de vencimiento editable
- pagos de solo interés
- pagos de solo capital
- pagos mixtos
- historial de pagos
- saldo de capital e intereses
- estados vigente, vencido y pagado

Este archivo se utiliza como marcador de despliegue para verificar el flujo GitHub → Vercel.
